# Gestão de Vendas do Quartel

Quero criar um sistema web de gestão de vendas para meu pequeno negócio de venda de salgados, baguetes e refrigerantes dentro de um quartel.

O sistema deve ter aparência profissional, moderna e minimalista, com cores verde escuro, branco e cinza. Deve funcionar perfeitamente tanto no computador quanto no celular.

O nome do sistema será Gestão de Vendas.

Quero um menu lateral com as seguintes opções:

Dashboard

Nova Venda

Histórico de Vendas

Militares

Produtos e Estoque

Fiado / Contas a Receber

Financeiro

Relatórios

Configurações

Na página inicial, quero cards mostrando:

Faturamento do dia.

Total recebido.

Total vendido fiado.

Dívidas pendentes.

Lucro estimado.

Quantidade de vendas.

Produtos com estoque baixo.

Quero uma interface organizada, com gráficos, tabelas e botões intuitivos.

O sistema será utilizado para registrar vendas feitas a militares, identificando nome, posto ou graduação e companhia, além de controlar pagamentos à vista e fiado.

IMPORTANTE: Neste primeiro momento, concentre-se em criar uma excelente estrutura visual, navegação completa e identidade visual profissional. Organize o projeto com código limpo e componentes reutilizáveis, deixando a estrutura preparada para integração com Supabase e futuras melhorias pelo GitHub e Codex.

Não quero um site institucional ou uma landing page. Quero um sistema administrativo real, com painel de gestão.
